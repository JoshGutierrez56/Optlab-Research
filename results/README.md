# Verified results

Reproduce the committed evidence with Python 3.12:

```bash
pip install -e ".[dev]"
python scripts/run_synthetic_signal_demo.py --output-dir results --seed 42
```

The demo forms a lagged 12-to-2-style synthetic momentum signal, buys the top quintile, shorts the bottom quintile, and deducts 20 bps per unit of one-way turnover.

Recorded result (132 months):

- Gross annual return: -2.36%
- Gross Sharpe: -0.293
- Net annual return: -3.49%
- Net Sharpe: -0.433
- Net maximum drawdown: -37.62%
- Average monthly turnover: 48.17%

Artifacts:

- `synthetic_signal_summary.json` - metrics, manifest, seed, and claim boundary
- `synthetic_signal_returns.csv` - gross and net return series
- `synthetic_signal_cumulative.png` - gross/net cumulative result
- `synthetic_signal_report.html` - portable report generated by the repaired reporting layer

The negative result is retained intentionally. It verifies that the framework reports outcomes honestly. The data are simulated and do not validate or invalidate momentum in historical markets.
